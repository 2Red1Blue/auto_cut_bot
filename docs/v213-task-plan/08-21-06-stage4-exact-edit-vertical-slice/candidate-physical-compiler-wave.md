# Candidate-local physical compilation

Continue the actual editorial/media join and replayed v2 presentation map.
This wave implements pure compilation, not Store commitment, physical Admission,
Recipe or publication permission. Those consumers must reread exact predecessors
and independently recompute results; constructing a result DTO grants nothing.

## Ownership

- `calibration_contract`: new candidate-local dialogue guard.
- `calibration_migration`: shared speech-grouping leaves and guard tests; preserve
  existing whole-root API behavior without creating a replacement root.
- root: native candidate compiler and bounded exact-search tests.
- `review_calibration_migration`: read-only independent review after freeze.

## Inputs and identities

Use the original root, candidate timed evidence, complete adaptive-window plan,
actual installed timed-speech profile and replayed v2 presentation map. Preserve
each hash; never flatten a piecewise clock, inject local speech into the root,
or construct an obsolete profile to satisfy the primitive compiler signature.

The speech guard derives known-speech protection from actual local Transcript
and FSMN evidence and the registered policy. It validates dual producer,
calibration, adapter, policy and clock identities. Model identity is bound by
the profile and committed producer reader, not inferred from words. Rolled
ranges must remain within proven local coverage; only true source boundaries
may clip rolls. Word-only evidence never satisfies complete dialogue.

The physical compiler receives an explicit source-bound desired/required video
range and explicit boundary policy. These are lower-level query inputs, not
proof that an editorial requirement selected this domain. The subsequent
Blueprint/SpanPolicy compiler owns domain derivation, VLM editing-mode/style
preferences and semantic-duration closure. This wave cannot declare those done.

## Complete endpoint relation

1. Enumerate real video starts in desired-start..required-start, and real video
   ends in required-end..desired-end (probe-proven source end is out-only).
   Coarse VLM ticks need not themselves be decoded frame PTS.
2. For each endpoint, replay its rational v2 mapping and use ordered sample
   indices to enumerate **all** samples within floor/ceil plus explicit sync
   tolerance, within the candidate's proven audio coverage. No nearest/top-k
   sampling. An endpoint outside common presentation coverage is infeasible.
3. Conjoin visual stability, shot-boundary, subtitle clearance and known-speech
   protection. Every full selected A/V pair must occupy one common continuous
   presentation segment. No endpoint-only proof can bridge a gap.
4. Enumerate all surviving start/end pairs. Use explicit video-pair and A/V-pair
   work limits; exhaustion rejects the entire search, never returns the best
   prefix. Reject empty relation. Retain only the canonical minimum and a
   streaming relation digest, not the complete relation in memory.
5. Report exact logical four-domain cardinality, actually visited aligned-pair
   cardinality, feasible cardinality and domain/relation hashes. The relation
   digest uses versioned canonical endpoint enumeration, not unspecified dict
   order. Small-space tests independently exhaust the unfiltered Cartesian
   product to compare the **whole relation**, counts and canonical minimum.

Hard-rule-derived filtering is an exact relational restriction, not beam search
or a statistical completeness claim. Source/clock/profile hashes remain in the
result; a hash alone is never a certificate of complete search.

## Validation and limits

Require positive stable-region and subtitle-clearance policy values; retain
per-cue detector uncertainty. Preserve global frame/sample/visual/subtitle/shot
evidence and prohibit unknown/partial evidence. The compiler must not require
full-episode ASR. Cover non-frame coarse endpoints, VFR, fractional/negative
time, unequal tails, internal gaps, source-end sentinel, local ASR coverage,
VAD-only protection, subtitles/short shots, empty relation and budget exhaustion.

Run only provider-free checks on this Mac. Real native/DB/model acceptance is
on the desktop when private configuration and media paths are supplied.
