## 一、文档定位

本知识库文档是"素材AI自动化制作"技能体系的基础层，目标是把编导多年积累的**隐性剪辑经验**转化为**可被AI理解、执行、自查的显性规则**。

素材本质上是**"浓缩重剪版正片"**，核心目标是让观众看完之后**理解一段完整、有因果逻辑的故事**（或一条清晰的主题线索），同时保留短剧特有的强情绪节奏。

- 服务对象：AI自动生产素材流程中的选片、故事线/卖点判断、段落取舍、结尾钩子设计等环节
- 本期范围：**原剧情剪辑**、**混剪**两种素材形式；素材内容全部来自原片剪辑，不涉及字幕/配音的新增（转场特效除外）
- 核心待解决问题：AI自动剪辑成片经常出现**该剪的关键因果节点被剪掉、不该剪的水戏被保留、情绪基调在段落间无逻辑跳跃**
- 后续规划（不在本篇展开）：解说/二创剪辑思路、镜头级素材打分标准、字幕与配音规范、失败案例库

## 二、核心问题诊断：为什么"爆点堆叠"会失败

1. **因果断裂会被立刻察觉**：一旦某个转折缺少铺垫或缺少后续交代，会产生"剪得莫名其妙"的强烈违和感
2. **情绪基调无过渡的硬切，会打断沉浸感**：情绪节奏被强行拉扯，观众会本能觉得"剪得很乱"
3. **多线索并行叙事极易散架**：每条线都剪一点，会因信息量不足而显得突兀、不可信
4. **"燃/甜"不等于"该保留"**：只按情绪强度选片，会把承担因果连接作用但不够"燃"的过渡剧情剪掉，最终是情绪高点的机械拼接，而非故事

**结论：剪辑的第一优先级是"故事线（或主题线索）是否成立、是否清晰"，其次才是"情绪强度是否够高"，时长长短是结果而非目标。**

## 三、故事线剪辑核心原则

### 3.1 原则一：单主线优先，支线让位，宁短勿乱

- 判断主线的依据：男频默认以冲突/身份/逆袭线为主线，女频默认以情感发展线为主线，感情线/动作线只有在直接驱动或服务主线时才保留；无法明确判断类型时，选择戏剧张力最强、贯穿集数最多的一条线作为主线
- **核心提问**：这个片段是否直接服务于"当前选定主线"的因果链？是→保留；否→整体压缩或删除，不能只删台词留镜头
- **宁短勿乱**：为了讲清楚一条主线，成片时长比原计划短也应优先保证故事线清晰，不能为了凑时长强行加入第二条线索或大量支线内容。**时长不是剪辑的目标，故事线清晰度才是**

### 3.2 原则二：因果链完整，允许压缩过程但不能跳过关键节点

主线遵循"起—承—转—合"四个关键节点，可大幅压缩每个节点内部的过程性内容，但四个节点本身不能被跳过或替换：

- 起（起因）：主线冲突/关系的触发点
- 承（发展）：矛盾或情感的第一轮推进
- 转（转折）：关键转折点，情绪或信息量的最大跃升点
- 合（结果）：主线阶段性收束；如原剧未完结，可替换为情绪最高点的悬念截断

**执行规则**：先标出四个节点对应的原始片段作为不可删除的绝对锚点，再围绕锚点填充/压缩中间的过程性内容。

### 3.3 原则三：段落间情绪基调必须有逻辑过渡，禁止无衔接硬切

- **合法过渡**：相邻片段情绪基调转变时，必须能在剧情逻辑上说清楚"为什么会转变"
- **非法过渡**：情绪高涨的片段直接硬切到毫无关联的另一种情绪片段，中间没有任何因果或时间关系交代
- **AI自查规则**：每次段落切换都要问"上一段的结果，是否直接导致或解释了下一段的开始？"若不成立，可采用以下任一方式处理：
  1. **原片衔接**：从原片中寻找能交代因果/时间关系的过渡片段插入（如回忆/闪回镜头、角色对白提及背景的片段）
  2. **转场特效衔接**：使用闪白、叠画等转场特效软化跳跃感，提示"时间/场景发生了跳跃"，但不新增文字/配音内容
  3. 调整段落顺序使因果顺畅
  4. 判定其中一段属于支线，予以删除

## 四、本期剪辑形式范围：原剧情 与 混剪

### 4.1 两种形式的核心逻辑区别（定义澄清）

**原剧情剪辑的判断标准不是"是否单集/连续几集"，而是"各片段之间是否保持原片时间轴的顺序推进"。** 例如：第2集第10秒起 → 第5集第67秒止，再接第10集第5秒起 → 第12集第55秒止，只要片段按时间先后顺序排列、不倒序插入，即属于原剧情剪辑，中间被跳过的内容视为"压缩掉的过程性/支线内容"。

| 维度 | 原剧情剪辑 | 混剪 |
|---|---|---|
| 素材来源范围 | 可跨集、可不连续，但**片段间严格按原片时间顺序排列** | 可跨集数、跨场景，且**不要求按时间顺序**，按主题/逻辑串联 |
| 故事线的呈现方式 | 依赖**时间顺序**的因果链（起承转合按原始时间先后推进） | 依赖**主题/逻辑线索**的串联（不依赖时间顺序，但仍需有清晰的主题递进，不能随机堆叠） |
| 剪辑动作性质 | 以"取舍"为主：跳过不需要的段落，保留的段落间维持时间顺序 | 以"取舍+重排"为主：挑选服务同一主题的片段，按逻辑顺序（而非时间顺序）重新排列 |
| 背景信息处理 | 若跳过的内容较多导致背景信息缺失，需要衔接处理（见3.3） | 因跳跃/重排幅度更大，通常更依赖衔接处理 |

### 4.2 素材内容来源与衔接手法

- 本期两种形式均以**原片素材**（画面、原声、原字幕）为主体，不新增解说音轨、不新增字幕文案
- 交代背景/过渡衔接的两种合法手法：
  1. **原片素材衔接**：从原片中挑选可用于交代背景的片段（回忆/闪回镜头、对白提及背景的段落）
  2. **转场特效衔接**：闪白、叠画等转场手法，用于软化时间/场景跳跃带来的割裂感，属于剪辑技法范畴，不算"新增内容"
- 若原片缺少可用片段、转场特效也无法合理软化割裂感，则不做强行补充，转而调整开场钩子或结尾悬念的选择，规避对该背景信息的依赖

## 五、剧集核心卖点梳理

在选择开场钩子、决定原剧情/混剪走向、设计结尾悬念之前，**必须先明确本剧的核心卖点**，因为不同卖点类型决定了"哪些片段是不可删除的核心卖点片段"，也决定了混剪的主题线索选什么。

### 5.1 卖点识别的三个维度

1. **类型标签**：男频 / 女频 / 中性
2. **人物关系设定**：核心CP或核心对手之间的身份关系是否存在特殊张力（名义身份与真实情感错位、权力/地位落差、禁忌感设定、非人类设定等）
3. **情感/关系尺度定位**：纯爱甜宠 / 虐恋拉扯 / 带感官张力的擦边向

### 5.2 常见"关系张力型"卖点分类

不同人物关系设定的卖点，心理驱动逻辑不同，剪辑时需要突出的"张力点"也不同（以下仅作分类与选片决策依据，不涉及具体画面描述）：

| 卖点类型 | 关系设定核心 | 张力/心理驱动逻辑 | 剪辑需优先保留的片段 |
|---|---|---|---|
| 常规恋爱 | 无特殊身份张力 | 情感浓度本身（心动/宠溺/虐恋波折） | 情绪递进节点 |
| 伪骨科 | 名义类家人/兄妹关系，无血缘 | "名义身份"与"真实情感"之间的错位与试探 | 身份设定说明（明确无血缘）+ 情感线与身份设定的冲突瞬间 |
| 耽美/百合 | 同性情感线 | 突破常规异性恋叙事框架的情感张力 | 该CP关系递进的关键节点，需单独标注CP主线 |
| 人兽/异类恋 | 人类与非人类角色（妖、兽人、龙族等奇幻设定）的情感线 | "身份差异带来的禁忌感"与"情感真挚性"的反差 | 非人类身份的确立/揭示片段 + 情感关键节点 |
| 禁忌恋 | 受伦理/社会规范约束的关系（如身份悬殊到极端、伦理边界设定等） | 关系本身"不被允许"所带来的紧张感与代入感 | 关系被阻挠/被发现的冲突片段 + 情感坚持的关键片段 |
| 年龄差/姐弟恋 | 双方年龄或心智成熟度存在明显差距（设定为成年人） | "反差感"驱动的新鲜感与保护欲/依赖感 | 体现年龄差反差的互动片段 |
| 身份悬殊（豪门×灰姑娘） | 阶级/财富地位悬殊 | 阶级跨越带来的代入式满足感 | 身份差异被点明的片段 + 双方态度软化的关键节点 |
| 宿敌转恋人（欢喜冤家） | 双方最初为对手/竞争关系 | "从针锋相对到心动"的反差与拉扯感 | 对抗高光片段 + 态度转变的关键节点 |
| 契约/交易关系 | 因利益/协议建立的关系（契约婚姻、假结婚等） | "假戏真做"过程中真实情感逐渐显露的代入感 | 契约建立片段 + 情感真实流露的关键节点 |
| 替身/白月光对照 | 一方作为另一段关系的"替代品"存在 | "我要的是你，不是影子"式的身份确认张力 | 替身处境确立片段 + 身份被真正认可的关键节点 |
| 破镜重圆/失忆梗 | 因误会/意外分离后重新相遇 | "错过与弥补"带来的遗憾感与释然感 | 分离原因交代片段 + 重逢/记忆恢复的关键节点 |
| 多角/三角虐恋 | 存在第三方介入的情感博弈 | "选择与被选择"带来的悬念与代入焦虑 | 三方关系确立片段 + 抉择/摊牌的关键节点 |

> 以上分类用于帮助AI/编导判断"这条素材的核心卖点是什么、哪些片段是支撑该卖点成立的必要信息、哪些片段是该卖点的情绪高光点"，不涉及具体镜头内容的生成或描述。多个卖点类型可能在同一剧中叠加（例如"豪门身份悬殊"+"宿敌转恋人"），此时需要判断哪个是**主卖点**、哪个是**辅助卖点**，主卖点关键片段优先级最高。

### 5.3 卖点与剪辑决策的联动

- **开场钩子的选择**需要与卖点匹配：涉及身份/关系设定类卖点（伪骨科、人兽异类恋、替身文等）时，开场若完全不交代关系设定就直接进入情绪高光，观众会因不了解"这是什么关系"而困惑，因此这类卖点的开场往往需要极短地带出关系设定（哪怕只有一句台词/一个称呼），再进入情绪高光
- **混剪主题线索的选择**需要围绕核心卖点展开，而不是把该剧所有类型的高光片段混在一起
- **卖点关键片段优先于其他更"燃"但与卖点无关的片段保留**

## 六、剪辑模板体系（编导经验沉淀）

模板变量包括：**开场钩子类型**、**素材形式（原剧情/混剪）**、**核心卖点类型**。以下为结合实操经验沉淀的模板库，用户此前给出的示例（冲突开场）已纳入其中作为一种典型情况。

### 6.1 按开场钩子类型划分的基础模板

**A. 冲突开场模板**（男频向为主，女频虐恋、宿敌转恋人向也适用）

- 开场：冲突高光片段（对峙、争吵、肢体冲突、羞辱瞬间）
- 原剧情走向：按原片时间顺序推进冲突因果链（起因精简带出→冲突升级→关键转折→阶段性结果），中间可跨集拼接，但各片段保持时间先后顺序
- 混剪走向：从原片其他场景中挑选交代"关系由来/冲突背景"的片段（相识片段、身份设定说明、恩怨起源），按逻辑顺序拼接补齐背景
- 结尾钩子方向：冲突走向悬念——谁会赢/是否反击/关系是否破裂

**B. 情感高光开场模板**（女频向为主）

- 开场：情感高光片段（告白、心动瞬间、误会爆发）
- 原剧情走向：按时间顺序回溯至该高光片段之前的关系节点，顺剪推进至该片段，再适度延续
- 混剪走向：挑选关系发展不同阶段的高光片段（相识/心动/危机/和解），按逻辑顺序（非时间顺序）拼接，形成"关系发展速览"
- 结尾钩子方向：情感结局悬念——能否修成正果/误会能否解开

**C. 身份/实力反转开场模板**（男频向为主）

- 开场：身份反转或实力展示高光片段
- 原剧情走向：按时间顺序推进"起（被轻视）→转（身份/实力暴露）"因果链
- 混剪走向：挑选同一人设标签反复被印证的高光片段，强化人设分量感
- 结尾钩子方向：身份/实力还有多少未揭晓的悬念

### 6.2 按核心卖点类型划分的专属模板

**D. 关系设定前置模板**（适用于伪骨科、人兽/异类恋、禁忌恋等依赖"关系设定"才能成立的卖点）

- 开场：先用极短片段（一句称呼/一个身份说明镜头）点明关系设定的特殊性，紧接着切入该卖点的情绪高光片段（暧昧/心动/冲突）
- 原剧情走向：按时间顺序推进关系设定确立后的情感/张力发展
- 混剪走向：以"关系设定确立→张力试探→情感升级"为逻辑线索拼接跨集片段
- 结尾钩子方向：这段"不被允许/特殊"的关系最终走向的悬念
- **要点**：若关系设定不前置说明，观众极易对暧昧片段产生误解或困惑，此类卖点**关系设定说明片段的优先级高于常规起承转合节点**

**E. 悬念揭秘延后模板**（适用于强调"身份反转/真相揭晓"作为全片最大悬念的剧集，反转点不提前作为开场钩子，而是留到结尾）

- 开场：不用最大反转点作为钩子，而是用一个较小的悬念/异常信号作为开场（例如角色反常举动、一句意味不明的台词）
- 原剧情/混剪走向：按时间顺序（或逻辑线索）逐步铺陈线索，制造"越看越可疑"的追剧感，最大反转点保留到成片结尾
- 结尾钩子方向：反转点揭晓的瞬间或揭晓前一秒截断，形成"欲知后事如何"的最强钩子
- **要点**：与A/C模板（反转点前置）是互补关系，适合原片本身"悬念驱动"强于"冲突/情感驱动"的剧集，AI需先判断该剧是否属于此类型

**F. 关系对照模板**（适用于替身文/白月光对照、多角虐恋等需要呈现两段关系对比的卖点）

- 开场：先呈现"对照关系"的高光片段（如白月光与男主的旧情片段，或第三者与主角的互动），制造认知悬念
- 原剧情/混剪走向：以主角关系线为主线（遵循单主线原则），对照关系仅作为**背景信息**穿插出现，服务于主线情感的因果解释（如解释"为什么男主一开始态度冷漠"），不单独展开成平行的第二条主线
- 结尾钩子方向：主角关系能否战胜/摆脱对照关系阴影的悬念
- **要点**：这是"单主线原则"在多角色设定下的具体应用——两段关系看似并行，但剪辑上必须明确谁是主线、谁是背景对照，不能雨露均沾

**G. 日常渐进模板**（适用于甜宠/宠溺日常等无强反转、无强冲突的卖点，情绪曲线平缓型剧集）

- 开场：一个能体现关系甜度或反差萌的小片段（不依赖强冲突，依赖"反差感"或"高甜瞬间"）
- 原剧情走向：按时间顺序推进多个"宠溺细节"的渐进积累，无需强转折点，但仍需保留"起（初识/隔阂）→合（关系确认）"的基本首尾锚点，避免变成纯随机的甜蜜片段拼贴
- 混剪走向：以"宠溺瞬间的递增强度"为逻辑线索拼接（从小细节到明显示爱），而非时间顺序
- 结尾钩子方向：下一步关系进展的期待感（"两人会不会在一起"），而非强悬念

### 6.3 模板速查表

| 模板 | 适用场景 | 原剧情走向要点 | 混剪走向要点 | 结尾钩子方向 |
|---|---|---|---|---|
| A. 冲突开场 | 男频/女频虐恋/宿敌恋 | 顺时间线推进冲突因果 | 拼接关系由来/冲突背景 | 冲突走向悬念 |
| B. 情感高光开场 | 女频情感线 | 回溯节点后顺剪至高光点 | 拼接关系发展各阶段高光 | 情感结局悬念 |
| C. 身份/实力反转开场 | 男频逆袭/身份剧 | 顺因果链交代反转全过程 | 拼接同一人设的多次高光印证 | 身份/实力further揭晓悬念 |
| D. 关系设定前置 | 伪骨科/人兽异类恋/禁忌恋 | 设定确立后推进张力发展 | 设定确立→张力试探→情感升级 | 关系走向悬念 |
| E. 悬念揭秘延后 | 悬念/真相驱动型剧集 | 逐步铺陈线索，反转留结尾 | 同左，按逻辑线索铺陈 | 反转揭晓前一秒截断 |
| F. 关系对照 | 替身文/白月光/三角虐恋 | 主线为核心CP，对照关系作背景 | 同左，对照关系不单独成线 | 主角关系能否战胜阴影 |
| G. 日常渐进 | 甜宠/宠溺日常 | 渐进积累宠溺细节，保留首尾锚点 | 按甜度递增逻辑拼接 | 关系进展期待感 |

> 无论采用哪种模板，**卖点关键片段（见第五节）始终优先于模板本身的常规节点**：若某个模板节点与卖点关键片段冲突，以保留卖点关键片段为准。同一剧集也可能需要组合使用多个模板（例如D+A：关系设定前置后接冲突走向），AI应根据原剧本实际内容灵活匹配，而非机械套用单一模板。

## 七、通用剪辑思路

### 7.1 开场依然遵循"强吸引法则"，但后续必须回归故事线

前几秒仍然需要冲突/悬念/反差/关系设定来完成"截流"，但开场之后必须立刻回落到第三节的故事线逻辑上。

### 7.2 剪辑节奏规则

- 关键因果节点/卖点关键片段：保留完整时长，给够反应时间
- 过程性/铺垫性内容：可压缩，但需保留"发生了什么"的最低限度信息
- 情绪高点的密度需服务于因果链，而非机械均匀分布

### 7.3 结尾钩子设计原则

结尾截在主线（或主题线索）情绪/悬念的最高点，具体方向按第六节模板对应的钩子方向执行。

## 八、男频剪辑思路（故事线视角）

### 8.1 受众心理画像

尊严补偿与掌控感——观众需要先理解"为什么弱"，才能真正享受"如何强"。

### 8.2 高频题材与主线类型

- 赘婿/废物逆袭：起（被轻视）→承（隐忍/暗中积蓄）→转（身份/实力暴露）→合（地位确立、反派臣服）
- 战神归来/兵王：起（回归后被轻视）→承（多次隐忍或小规模试探性亮相）→转（关键危机中全力出手）→合（身份公开、全场震慑）
- 复仇/资本对决：起（被陷害/夺权）→承（暗中布局、收集筹码）→转（关键对决/揭穿阴谋）→合（夺回属于自己的一切）
- 超能力/异能觉醒：起（能力初现/受质疑）→承（能力逐步验证）→转（关键战斗中全力展现）→合（获得认可或碾压强敌）
- 龙王/隐藏大佬：结构与赘婿逆袭高度相似，起点人设更"深藏不露"

### 8.3 主线与支线的取舍

- 感情线只有在直接构成主线冲突的动因/筹码时才保留
- **绝不能出现的剪辑错误**：主线冲突"承"阶段的紧绷情绪中插入无关的谈情说爱片段
- "忍"的铺垫戏份可压缩但不能整体删除

### 8.4 与模板/卖点的衔接

- 多适用模板A（冲突开场）、C（身份反转开场）
- 若存在关系张力型卖点（伪骨科、人兽异类恋等设定下的男频剧），结合模板D

## 九、女频剪辑思路（故事线视角）

### 9.1 受众心理画像

情感代偿与被珍视感——需要依托清晰可信的情感发展轨迹，而非零散的"宠溺瞬间合集"。

### 9.2 高频题材与主线类型

- 闪婚/契约婚姻：起（因利益/意外结合）→承（好感与误会交织）→转（危机或表白）→合（关系确立）
- 豪门恩怨/先婚后爱：起（联姻/身份悬殊）→承（态度软化）→转（关键事件情感爆发）→合（真心确认）
- 替身文/白月光对照：起（替身处境）→承（男主态度动摇）→转（关键表白）→合（身份被认可）
- 虐恋/错过重来：起（误会/破裂）→承（隐忍/试探）→转（真相揭晓）→合（重新在一起）
- 甜宠/宠溺日常：起（初识/隔阂）→承（宠溺细节积累）→转（关键守护/表白）→合（关系升温确认）

### 9.3 主线与支线的取舍

- 动作/复仇支线只有在直接服务情感主线时才保留
- **绝不能出现的剪辑错误**：情感主线"承"阶段的细腻互动中插入无关的大篇幅打斗/商战戏
- 误会/心结段落可压缩但不能整体删除

### 9.4 与模板/卖点的衔接

- 多适用模板B（情感高光开场），虐恋类可结合A，替身/白月光类适用F，甜宠日常类适用G
- 若存在关系张力型卖点（耽美CP、伪骨科等），结合模板D，将该CP主线关键节点作为独立必保留片段

## 十、三类型故事线速查对比表

| 维度 | 男频 | 女频 |
|---|---|---|
| 主线类型 | 冲突/身份/逆袭线为主 | 情感发展线为主 |
| 支线保留条件 | 仅当支线直接触发主线冲突或构成筹码 | 仅当支线直接服务/催化情感主线 |
| 起（触发点） | 被轻视/身份危机 | 因利益结合/误会产生 |
| 承（发展） | 隐忍蓄力、暗中布局 | 相处中好感与误会交织 |
| 转（转折） | 身份/实力暴露、关键对决 | 危机/表白、真相揭晓 |
| 合（结果） | 地位确立、反派臣服 | 关系确立、情感升华 |
| 常用模板 | A、C（结合D） | B（结合A/F/G，结合D） |
| 段落过渡禁忌 | 蓄力紧绷阶段硬切进无关甜蜜戏 | 情感细腻铺垫阶段硬切进无关打斗戏 |

## 十一、AI自动化应用要点

1. **卖点识别（第一步）**：识别类型标签、人物关系设定、情感尺度定位，明确核心卖点（含主卖点/辅助卖点判断），标注卖点关键片段
2. **主线识别**：识别原剧本所有情节线 → 依据类型标签与卖点选定唯一主线 → 标记其余为支线
3. **因果锚点标注**：沿主线标出"起承转合"四节点对应片段，作为不可删除锚点
4. **模板匹配**：根据开场钩子类型、素材形式、核心卖点类型，从第六节模板库中匹配（可组合），决定后续剪辑走向
5. **段落过渡合法性校验**：检查前后段落情绪基调是否有因果/时间逻辑衔接；原剧情检查时间顺序合理性，混剪检查主题线索连贯性；不合法则依次尝试原片衔接→转场特效衔接→调整顺序→拆分独立素材
6. **人工复核锚点**：优先检查"卖点是否清晰传达""主线是否唯一清晰""因果节点是否完整""是否存在情绪基调无衔接硬切"
