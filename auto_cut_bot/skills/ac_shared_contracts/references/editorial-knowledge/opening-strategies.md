# 开场策略

## 剪辑路径选择

系统先选择剪辑路径：`montage` 或 `original_chronological`。两条路径都必须有高光开头，并在黄金三秒内建立人物、冲突或观看赌注。原剧情顺剪只是不做未来预览，首个高光来自原片 mainline 的自然开场。

## 两种可接受开场策略

### causal_explanatory_no_reprise（默认）

先用完整高光提出结果、危机或反常选择 → 回到更早前因解释 → 解释后继续推进 → **正文不重放片头**。

### causal_explanatory_delayed_reprise

同样先解释前因并至少完成一次新推进 → 之后才允许在稍后位置重放高光 → 必须声明新增功能。

## 共同要求

- 开头足够高光
- 正文与开头存在强因果关系
- 不能快速接重复内容
- 历史 `future_preview_reprise` 仅为旧脚本兼容，不作为新剧默认剪法

## Stage 路由约束

全剧理解优先顺序见 `story-understanding-and-opening-selection.md`：

- Story Catalog 先发现完整故事弧
- 窗口中的高光只进入候选库，不得先锁定开头再倒推故事
- 正式开头必须在 Story Script 中提交 `opening_selection`
- 本地门禁检查它是否经过全剧主线、完整故事弧和真实证据联合验证

## 错误反例（仅用于回归测试）

Arya 案例中的以下模式均为错误反例，只用于阻断与回归测试，不能作为新项目剧情证据：

- 片头高光—正文机械重复
- 弱信息开头
- 删掉背叛台词
- 删掉设问后的感情兑现
- 无桥接跳到 ep025
- 黑龙胜利后反接红龙胜利
