# 高光开头（前 3 秒）筛选合同

## 目标

两种剪辑模式的第一个有效画面和声音都必须有明显抓力。平淡叙事、普通走位、看风景、无功能空镜和无法建立冲突的慢铺垫，不得作为高光开头。

高光必须经过“全剧理解—完整故事弧—开头”联合筛选。窗口标出的高光只是候选，不是最终开头；不能先锁一个局部刺激片段，再反过来编造或压缩故事线。

## 优先信号

### 视觉信号

- 强肢体冲突：掌掴命中、推倒/摔落、掀桌、泼液体、撕衣、揪住衣领。
- 极致面部特写：怒吼、瞬间痛哭、嚣张狂笑、黑化冷笑；手机画面优先使用满屏脸或眼睛的大特写。
- 高张力两性画面：壁咚/床咚、捏下巴、意外扑倒、拉扯领带、浴袍滑落、近距离对视。该类信号必须服从剧种适配和平台安全要求，不能作为所有剧的默认模板。
- 身份/利益反差：破旧服装与高价值道具同框、高定出场、股权/离婚协议等关键文件砸桌；道具必须能在一秒内说明利益冲突。

### 听觉信号

- 生理刺激音效：掌掴、骨裂、撕裂、急刹、掀桌等具有明确来源的声音。
- 极端人声：惨叫、怒吼、命令、威胁、强烈喘息或明显的心跳/倒计时效果。
- 高钩子台词：开口即背叛、冲突、身份、复仇或未解危机；删除废话和普通寒暄。

## 选择与切点

1. 第一帧或最迟前 3 秒必须出现至少一个强视觉/听觉信号，优先同时具备画面与声音信号。
2. 高光必须在前 8 秒内说明“谁对谁做了什么”或至少建立可追踪的关系、冲突和赌注；只有爆炸、打人或道具声而没有人物关系的片段不能直接通过。
3. 评分使用“主线改变权 + 核心冲突事件 + 主角命运/关系变化 + 信号强度 + 关系可读性 + 赌注/未解问题 + 与正文因果关系 + 边界安全 + 重复风险”，不允许只按动作刺激度或解释性台词排序。实际背叛、救援、反击、选择和关系决裂优先于“我不爱你”一类背景解释；解释性台词不能替代更强的核心事件。
4. 候选窗口起点不是最终入点。必须连续检查候选起点前后至少 3 秒，剔除无功能闪黑、包装、静帧或空镜，并将 `source_start` 对齐到第一帧有效剧情画面。
5. 动作核心帧可以作为视觉锚点，但源片入点必须从完整动作或完整台词的安全边界开始；不得为了卡掌掴接触帧、皇冠掉落或道具落桌峰值而切出半个动作、孤帧或半句台词。
6. 有明确叙事功能的黑场必须单独声明；普通闪黑不得保留。源片前导闪黑与 Recipe 人为生成的 `black_separator` 必须分开检查。
7. 高光正文重复时，必须先完成前因解释和至少一个新的因果/关系推进；否则阻断。高光与正文不重复时，正文仍必须能解释高光并继续推进。
8. 如果没有达到门槛的候选，返回 Story Script 修订或人工复核，不得把普通开场强行标为高光。
9. 正式开头必须与一个完整故事弧绑定，并能由正文解释、推进和落到同线 Hook；候选无法形成完整因果弧时必须淘汰，而不是倒推故事。

具体字段、失败码和边界流程见 [opening-effective-frame-policy.md](opening-effective-frame-policy.md)。

## 类型适配

肢体冲突、两性张力、身份反差、极端情绪和狠台词是可迁移的信号类别，不是所有剧的固定剧情模板。悬疑优先使用关键证据/异常发现，家庭伦理优先使用关系决裂/公开对质，男频逆袭优先使用身份或权力反转，玄幻优先使用规则/能力异常；最终仍需满足同一主线和真实原片证据。

## 失败反例

- 第 0 秒是走路、看风景、普通坐下或无冲突对话。
- 只有强音效/强动作，但观众无法判断人物、关系和赌注。
- 从台词中间、动作中间或反应尾部截入。
- 候选窗口前存在约 2 秒闪黑，却把窗口起点直接当作成片入点。
- 只验证了成片人为添加的黑场，没有验证源片冷开场前导是否应被删除。
- 选出的“高光”只是未来内容预览，正文马上机械重复。
- 为追求刺激，把不属于当前剧种或主线的暧昧、暴力、道具镜头强行置顶。
