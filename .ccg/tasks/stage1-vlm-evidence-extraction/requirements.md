# Stage 1：真实 VLM Evidence Extraction

## 问题

现有验证只证明媒体预检、精确剪辑、渲染与本地 QC 正确；语义链使用受控 fixture，未调用视觉语言模型。因此它不能证明真实剧集输入能产生可信、可追溯的叙事证据。

## 本任务目标

在不引入旧 pipeline 依赖的前提下，完成一条可本地运行的 VLM 证据垂直切片：从已预检视频的可复算帧样本出发，调用已配置的 VLM，严格解析返回，持久化可审计证据，并将合格证据交给现有语义链。

## 必须满足

- 每次请求绑定：输入媒体内容哈希、帧样本的 PTS/哈希、提示词模板及版本、模型标识与请求参数。
- 保留原始模型响应（或受保护的不可变 BlobRef）及其哈希；解析结果必须能追溯到它。
- VLM 仅能产出语义观察和带证据的候选事实，不能写入路径、PTS 边界、Recipe 或发布决定。
- 不合规 JSON、未知 frame id、越界引用、超预算、提供商失败和低置信结果均显式失败或隔离，绝不静默降级为“无内容”。
- 单元测试采用 fake provider；真实 smoke test 必须显式 opt-in，默认不会泄漏密钥或让 CI 依赖外部服务。
- 真正的验真必须至少使用一段真实视频、真实提取帧和真实 VLM 响应，并形成持久化 Artifact/Receipt 证据；在此之前不得宣称整剧语义链已验证。

## 非目标

- 本任务不接外部发布平台。
- 不让 Agent Runtime 直接调用 VLM 或绕过 Kernel Command。
- 不复用旧 pipeline 的 Stage、ArtifactBus、Policy 或业务默认值。
- 不在没有用户提供/本地已配置可用凭据的情况下伪造“真实 VLM 已运行”。
